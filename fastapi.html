FastAPI 底層架構與請求生命週期

了解 FastAPI 為什麼擁有與 Node.js / Go 媲美的高效能，以及 Starlette 與 Pydantic 在其中的分工。

1. Uvicorn & ASGI

Uvicorn 是極快的 ASGI (Asynchronous Server Gateway Interface) 伺服器，負責處理非同步網絡連接 (TCP/HTTP/WebSockets)，是 FastAPI 運行的基石。

2. Starlette Web 框架

FastAPI 繼承並擴充了 Starlette。Starlette 提供強大的路由 (Routing)、中間件 (Middleware)、WebSockets 以及非同步 async/await 支援。

3. Pydantic 資料驗證

Pydantic 負責強類型的資料解析與驗證。它能自動把傳入的 JSON 轉為 Python 物件，遇到無效資料時自動拋出 422 錯誤。

# 5-min-FastAPI

- 完整學習路線與章節：從基礎 CRUD、路由參數、Pydantic 資料驗證，到依賴注入（Dependency Injection）、JWT 身份認證、WebSockets 即時通訊以及非同步處理（Async/Await）。

- 互動式 Code Sandbox：你可以在線上直接修改 Python FastAPI 代碼，並即時模擬 API 發送請求（GET, POST, PUT, DELETE）與即時查看 JSON 回應。

- 自動生成 Swagger UI / OpenAPI 預覽：體驗 FastAPI 最強大的特色之一——自動化 API 文件。

- 即時架構圖與知識點拆解：視覺化展示 Request -> Middleware -> Dependency Injection -> Route -> Response 的運作流程。
